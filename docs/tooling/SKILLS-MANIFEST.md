## Three findings that would have bitten whoever installed these

**1. `graphify` is not the package name.** The PyPI distribution is **`graphifyy`** — one character
off — while the CLI and skill are both called `graphify`. `pip install graphify` fetches something
else entirely. Any install line must pin `graphifyy` exactly. This is the shape of a supply-chain
mistake that reads as a typo.

**2. Four tools ship default-on egress**, each with a different off-switch, and none of them
announces it at install time: `gstack` (code and diffs to a second model provider, plus Supabase
telemetry), `agent-skills-cli` (`https://www.skills.sh/tele/t` on every install/find/update),
`strix` (PostHog **and** Scarf), `claude-mem` (prompts and transcript context by default).

**3. `react-bits` is "MIT + Commons Clause"**, which reads permissive and is not OSI open source.
Using components inside the product is allowed; selling or sublicensing a ported version is not —
which is exactly what a Phase 03 downloadable theme might do.

Fourth: graph output lands in-repo (graphify-out/, GRAPH_REPORT.md) and the README's team section suggests committing it; .gitignore has no graphify entry, so this needs an ignore rule before any run.
- **Security review outcome** — 1) Package name is `graphifyy`, not `graphify` — a one-character-off PyPI name while the CLI and skill are called `graphify`. Any manifest entry must pin `graphifyy` exactly; `pip install graphify` fetches something else entirely. 2) `--project` install mutates committed .claude/settings.json and CLAUDE.md, both CI-enforced here — must be done by hand and reviewed, never by running the installer. 3) `graphify hook install` is unreviewed auto-execution on commit/checkout; the owner's "no unreviewed auto-update" constraint rules it out. 4) The PreToolUse command is the bare `graphify` with no absolute path, so it breaks or stalls 10s per Read/Bash if PATH differs. 5) Pre-1.0 (0.9.92) with ~25 pinned tree-sitter grammar deps — a wide transitive surface for a Laravel/Blade repo that needs only PHP/JS/SQL. 6) Secret exclusion is a heuristic, not a guarantee (see privileges/network): docs and PDFs that happen to contain credentials are in the Pass 3 egress path unless GRAPHIFY_BACKEND=none or --code-only is set. 7) Graphify Cloud is a paid upsell whose data transmission is undocumented — owner decision, and nothing in the local flow should be pointed at it. So on the specific worry raised, it does not ingest .env or secret files by default and does not upload code.
