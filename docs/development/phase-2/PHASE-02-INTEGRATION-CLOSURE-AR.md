## ٤. التحقّق على `main` المتكامل

**بوابة النتائج المعروفة على `25cf8182`:**

```

الأخطاء             0   (المتوقَّع دائماً: 0)
التخطّيات            1   (البيان يعلن 1)
GATE EXIT           0
```

> «موافق: مجموعة النتائج المرصودة تطابق البيان بالضبط — فاشلان مُعلَنان، تخطٍّ واحد مُعلَن، صفر
> أخطاء، ولا شيء غير مُعلَن.»
>
> «وهذه **ليست** شهادة بأن المجموعة خضراء، بل شهادة بأنها تفشل وتتخطّى الاختبارات التي سجّلها
> المشروع بالضبط، للأسباب التي سجّلها.»

وعلى كل دمج من الثلاثة كانت الحالة **ثمانية من تسعة خضراء**، والإخفاق الوحيد هو قائمة التحقق: لا
فحص أمني فاشل، ولا انحدار، على أي دمج.

**تحقّق محلّي قبل كل دفع:** `Feature/Security` كاملة ٤٧٤٣ ناجحاً وتخطٍّ واحد وصفر فشل (٢٠٠٨٠
تأكيداً) · Unit ٧٢١ · Contract ٢٧ (عقد Flutter غير متأثر) · سيناريوهات بوابة الإشهاد ٥٨/٠.

**و`ci.yml`** — الملف الوحيد الذي لمسه طلبان — فُحِص مباشرةً بعد الدمج لا ثقةً بنظافة الدمج
النصّي: YAML سليم، المهامّ الستّ قائمة، وتغييرات **كلا** الطلبين موجودة.
