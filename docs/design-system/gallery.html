Brand

The ramp is derived from the merchant's own logo mark (hue 172°), not invented. --ss-brand is the 800 step because it is the lightest one that clears 4.5:1 against white for button labels; --ss-focus-ring is 700, the lightest that clears 3:1 for non-text contrast.

Buttons

Solid danger is reserved for the confirming action in a dialog. Row-level deletes use the quiet variant, so a long table is not a wall of red.

Form fields

Inputs are 16px: anything smaller makes iOS Safari zoom the viewport on focus. The invalid state keys off aria-invalid, so the visual and the accessible state cannot drift apart.

Card, toolbar and table

Table cells use text-align: start, so the whole table mirrors under dir="rtl" with no second stylesheet. Sortable headers are real <button>s carrying aria-sort.
